**Space Mission 62 (SM62)** is a wired mechanical split keyboard with 62 programmable keys, low-profile switches, and a color IPS display on each half

The default layout includes a base layer and a navigation layer

## Overview and Package Contents

![Space Mission 62 — overview](/images/sm62/sm62_view.jpg)

1. Reset button
2. Boot button
3. Host USB-C port for connecting to a computer
4. Side USB-C port for connecting the halves
5. Auxiliary opening for disassembling the keyboard case
6. Silicone feet
7. Magnetic stands for a 6° tilt

The halves attach magnetically for carrying. The PLA case includes sound insulation. Hot-swap sockets allow switches to be replaced without soldering

### Displays

Each half has a color IPS display. The stock firmware shows an animated splash screen and highlights the pressed key

### Package Contents

{{< details title="USB cables" closed="true" >}}

- One 1.5 m USB-A to USB-C cable with straight connectors
- One 0.5 m USB-C to USB-C cable with angled connectors for connecting the halves

{{< /details >}}

{{< details title="Switch puller" closed="true" >}}

A switch puller is included for removing switches

{{< /details >}}

{{< details title="Magnetic stands" closed="true" >}}

Two magnetic stands for a 6° tilt are included

{{< /details >}}

## Connection

Either half can connect to the computer and act as the master

{{% details title="Wired connection" closed="true" %}}

{{% steps %}}

### Connect the halves

We recommend connecting the side USB-C ports of the two halves with the included USB-C to USB-C cable first

### Connect the keyboard to your computer

Connect the host USB-C port of either half to your computer using the USB-A to USB-C cable

{{% /steps %}}

## Firmware Update

The firmware file and update instructions are available in the [firmware selector](https://docs.eh.industries/firmware/) — select **Space Mission 62**

{{% details title="Entering the bootloader" closed="true" %}}

Use either method for the half you want to update

**Reset button**

{{% steps %}}

### Connect the half to your computer

Use the host USB-C port

### Quickly press Reset twice

The half will enter bootloader mode and appear on your computer as a removable drive

{{% /steps %}}

**Boot button**

{{% steps %}}

### Disconnect the half from your computer

Press and hold Boot

### Connect the half while holding Boot

Keep holding the button while connecting the host USB-C port to your computer. Release Boot after connecting — the half will appear as a removable drive

{{% /steps %}}

## Care and Maintenance

- Periodically remove dust and dirt from the case using a dry or slightly damp cloth

{{< callout type="warning" >}}
Do not apply excessive pressure to the displays when cleaning
{{< /callout >}}

{{< callout type="error" >}}
Do not use aggressive cleaning agents: acetone, gasoline, solvents (646, white spirit), concentrated acids or alkalis
{{< /callout >}}

{{< callout type="warning" >}}
Do not allow liquid to get inside the device
{{< /callout >}}
