**Space Mission 62 (SM62)** — проводная механическая сплит-клавиатура с 62 настраиваемыми клавишами, низкопрофильными переключателями и цветным IPS-дисплеем на каждой половинке

В раскладке по умолчанию предусмотрены основной и навигационный слои

{{< /details >}}

## Обзор и комплектация

![Space Mission 62 — обзор](/images/sm62/sm62_view.jpg)

1. Кнопка Reset
2. Кнопка Boot
3. Интерфейсный разъём USB-C для подключения к компьютеру
4. Боковой разъём USB-C для соединения половинок между собой
5. Вспомогательное окно для разбора корпуса клавиатуры
6. Силиконовые ножки
7. Магнитные подставки для наклона в 6°

Половинки соединяются магнитами для переноски. Корпус из PLA-пластика дополнен шумоизоляцией. Хотсвап-сокеты позволяют заменять переключатели без пайки

### Дисплеи

На каждой половинке установлен цветной IPS-дисплей. В штатной прошивке дисплеи показывают анимированную заставку и подсветку нажатой клавиши

### Комплектация

{{< details title="Кабели USB" closed="true" >}}

- Кабель USB-A на USB-C длиной 1,5 м с прямыми разъёмами — 1 шт
- Кабель USB-C на USB-C длиной 0,5 м с угловыми разъёмами для соединения половинок — 1 шт

{{< /details >}}

{{< details title="Свитч-пуллер" closed="true" >}}

В комплект входит пуллер для извлечения переключателей

{{< /details >}}

{{< details title="Магнитные подставки" closed="true" >}}

В комплект входят две магнитные подставки для наклона в 6°

{{< /details >}}

## Подключение

К компьютеру можно подключить любую половинку — она станет главной (master)

{{% steps %}}

### Соедините половинки

Рекомендуется сначала соединить боковые разъёмы USB-C половинок комплектным кабелем USB-C на USB-C

### Подключите клавиатуру к компьютеру

Подключите интерфейсный разъём USB-C любой половинки к компьютеру кабелем USB-A на USB-C

## Настройка

Для переназначения клавиш и настройки клавиатуры используйте графический конфигуратор [Entropy](https://entropy.tools/ru/)

{{< details title="Настройка дисплея" closed="true" >}}

Откройте **Настройки → Дисплей** в Entropy. В записи показаны выбор половинки, режимы дисплея и общие настройки экранов

## Обновление прошивки

Файл прошивки и инструкция по обновлению находятся в [селекторе прошивок](https://docs.eh.works/firmware/) — выберите **Space Mission 62**

{{% details title="Вход в загрузчик" closed="true" %}}

Выполните один из двух способов для нужной половинки

**Кнопка Reset**

{{% steps %}}

### Подключите половинку к компьютеру

Используйте интерфейсный разъём USB-C

### Дважды быстро нажмите Reset

Половинка перейдёт в режим загрузчика и появится на компьютере как съёмный накопитель

{{% /steps %}}

**Кнопка Boot**

{{% steps %}}

### Отключите половинку от компьютера

Зажмите кнопку Boot

### Подключите половинку, удерживая Boot

Не отпуская кнопку, подключите интерфейсный разъём USB-C к компьютеру. После подключения отпустите Boot — половинка появится как съёмный накопитель

{{% /steps %}}

## Уход и обслуживание

- Периодически очищайте корпус от пыли и загрязнений сухой или слегка влажной тканевой салфеткой

{{< callout type="warning" >}}
Не прилагайте большое усилие к дисплеям при чистке
{{< /callout >}}

{{< callout type="error" >}}
Не используйте агрессивные чистящие средства: ацетон, бензин, растворители (646, уайт-спирит), концентрированные кислоты и щёлочи
{{< /callout >}}

{{< callout type="warning" >}}
Не допускайте попадания жидкости внутрь устройства
{{< /callout >}}
