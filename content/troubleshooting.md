## Первичная диагностика

{{< callout type="important" >}}
Первичная диагностика рекомендуется для исключения типовых проблем, не связанных с электронной частью продукции Ergohaven.
{{< /callout >}}

{{% steps %}}

### Смена устройства

Проверьте, проявляется ли неисправность на другом устройстве (ПК, ноутбук, планшет, смартфон и т.д). Если используется USB Hub, попробуйте подключиться напрямую либо сменить порт USB.

### Смена операционной системы

Проверьте, проявляется ли неисправность на другой операционной системе (Windows, macOS, Linux и другие).

### Смена интерфейса подключения

Если используется проводное подключение между половинками или компьютером, замените кабель между половинками и компьютером.

### Возврат к заводским настройкам / обновление прошивки

Перепрошейте устройство на стандартную прошивку. Скачать актуальные прошивки можно на [странице релизов](https://github.com/ergohaven/vial-qmk/releases/tag/latest).

### Обновление драйверов

Переустановите драйвер USB или Bluetooth на вашем устройстве (ПК, ноутбук и т.д).

{{< callout type="info" >}}
Встроенные драйверы Windows не всегда корректно работают с устройствами USB и Bluetooth. Рекомендуется использовать драйверы от производителя устройства.
{{< /callout >}}

## Неполадки при нажатии клавиш

{{< details title="Клавиша не срабатывает или срабатывает дважды" closed="true" >}}

Для диагностики поменяйте местами свитч с проблемного места на исправное:

- **Проблема переместилась вместе со свитчем** → свитч бракованный, замените его.
- **Проблема осталась на том же месте** → неисправен хотсвап-сокет или плата. Попробуйте пропаять контакты хотсвапа или выровнять контактные усики.

{{< /details >}}

{{< details title="Клавиша работает при недовставленном свитче, но не при полностью вставленном" closed="true" >}}

Скорее всего, отошёл хотсвап-сокет. Разберите половинку и осмотрите сокет с обратной стороны платы. Если контакты отошли от платы — пропаяйте их заново.

{{< /details >}}

{{< details title="Следы флюса на плате, клавиша работает нестабильно" closed="true" >}}

Остатки флюса после пайки могут сохранять токопроводность и вызывать нестабильную работу клавиш. Очистите плату мягкой зубной щёткой со спиртом или специальным спреем FluxOFF, после чего уберите остатки тряпкой или бумагой.

{{< /details >}}

{{< details title="Одновременно регистрируется не более 6 нажатий (нет NKRO)" closed="true" >}}

По умолчанию клавиатура работает в режиме 6-Key Rollover. Для включения N-Key Rollover откройте Vial, перейдите во вкладку **Keyboard Settings** и включите опцию **NKRO**.

{{< /details >}}

## Неполадки при работе с прошивкой

{{< details title="Как войти в режим загрузчика (bootloader) для прошивки" closed="true" >}}

Если стандартный способ через Vial не работает, используйте физический метод:

1. Отключите все кабели от половинок.
2. Зажмите кнопку **BOOT** на контроллере (либо верхнюю левую клавишу на левой половинке / верхнюю правую на правой).
3. Подключите кабель к компьютеру, не отпуская кнопку.
4. Отпустите кнопку — на компьютере должна появиться папка-хранилище.
5. Скопируйте файл прошивки (`.uf2`) в эту папку.

{{< callout type="info" >}}
На Windows папка может не открыться автоматически — проверьте раздел «Этот компьютер» рядом с локальными дисками.
{{< /callout >}}

{{< /details >}}

{{< details title="После обновления прошивки слетели макросы, Tap Dance и другие настройки" closed="true" >}}

Это может произойти при обновлении прошивки с изменением структуры раскладки. Решение:

1. Откройте файл сохранённой раскладки (`.vil`) в текстовом редакторе.
2. В секции `encoder_layout` замените все значения `-1` на `"KC_TRNS"`.
3. Загрузите исправленный файл через Vial.

Альтернативно: загрузите сначала старую раскладку, затем новую — иногда это помогает Vial корректно применить настройки.

{{< /details >}}

{{< details title="Ошибка при загрузке раскладки: argument out of range" closed="true" >}}

Ошибка возникает из-за несовместимости структуры старого файла раскладки с новой прошивкой. Откройте файл `.vil` в текстовом редакторе и скопируйте секцию `encoder_layout` из нового файла раскладки в старый, после чего загрузите его снова.

{{< /details >}}

## Неполадки с функцией RuEn

{{< callout type="info" >}}
RuEn — встроенная функция прошивки Ergohaven для управления переключением языкового режима непосредственно с клавиатуры. Для корректной работы важно, чтобы внутреннее состояние клавиатуры совпадало с раскладкой, выбранной в операционной системе.
{{< /callout >}}

{{< details title="RuEn не переключает раскладку" closed="true" >}}

1. Убедитесь, что используете **RuEn Toggle**, **RuEn En** или **RuEn Ru** — а не системную комбинацию клавиш.
2. Нажмите **RuEn Sync** для синхронизации состояния клавиатуры с системой.
3. Если на экране устройства доступен режим **Modern** или **Classic**, включите его — он показывает текущую раскладку внутри клавиатуры.

{{< /details >}}

{{< details title="RuEn не работает на macOS" closed="true" >}}

На macOS RuEn Toggle отправляет комбинацию **Ctrl+Space** (если включён режим Swap Ctrl/Gui для Mac).

Проверьте, что:
- Активирован режим Mac: нажмите **Toggle Ctrl Gui** — на экране должно появиться изображение яблока.
- Системная комбинация переключения раскладки совпадает с той, что отправляет клавиатура. Если используете нестандартную комбинацию — настройте макрос M30 на свою комбинацию и активируйте его через **RuEn M30**.

{{< /details >}}

{{< details title="Точка (.) печатает слеш (/) при русской раскладке" closed="true" >}}

Это связано с тем, что стандартная macOS-раскладка «Русская» отличается от «Русской PC». RuEn ориентируется на раскладку «Русская PC».

Решение: в настройках Vial (вкладка **Layout**) переключите тип русской раскладки на **PC**.

{{< /details >}}

{{< details title="CapsWord отключается при наборе русских букв Б, Х, Ю, Ж" closed="true" >}}

Проблема связана с тем, что в английской раскладке эти позиции не являются буквами. При использовании RuEn для переключения раскладки CapsWord работает корректно с русскими символами. Обновите прошивку до актуальной версии.

{{< /details >}}

## Неполадки трекболов

{{< details title="Плохая точность перемещения указателя, рывки при перемещении" closed="true" >}}

{{< callout type="info" >}}
**Повышенная точность указателя** (также известна как акселерация мыши) — функция, изменяющая скорость перемещения курсора в зависимости от скорости движения. При использовании трекбола её рекомендуется отключить для получения предсказуемого линейного перемещения.
{{< /callout >}}

{{< tabs items="Windows 10 / 11,macOS,Linux" >}}
  {{< tab >}}
В Windows эта функция называется **«Включить повышенную точность указателя»**. Чтобы её отключить:

1. Откройте **Параметры** (`Win + I`).
2. Перейдите в **Bluetooth и устройства** → **Мышь**.
3. Нажмите **Дополнительные параметры мыши**.
4. Перейдите на вкладку **Параметры указателя**.
5. Снимите галочку с **«Включить повышенную точность указателя»**.
6. Нажмите **Применить**, затем **ОК**.
  {{< /tab >}}
  {{< tab >}}
Способ отключения зависит от версии macOS.

**macOS Sonoma и новее:**
1. Откройте меню Apple → **Системные настройки**.
2. В боковом меню выберите **Мышь**.
3. Нажмите **Дополнительно**.
4. Переключите **Акселерацию указателя** в положение **Выкл.**

**Старые версии macOS:**
1. Откройте **Терминал** (Finder: Программы → Утилиты).
2. Введите команду и нажмите Enter:
   ```bash
   defaults write .GlobalPreferences com.apple.mouse.scaling -1
   ```
3. Выйдите из системы или перезагрузите компьютер.
  {{< /tab >}}
  {{< tab >}}
**GNOME (Ubuntu, Fedora и др.):**
```bash
gsettings set org.gnome.desktop.peripherals.mouse accel-profile flat
```

Проверить результат:
```bash
gsettings get org.gnome.desktop.peripherals.mouse accel-profile
```
Должно вернуть значение `flat`.

**KDE Plasma:**
Откройте **Системные настройки** → **Устройства ввода** → **Мышь**, найдите **Профиль акселерации** и выберите **Плоский**.
  {{< /tab >}}
{{< /tabs >}}

## Неполадки с RuEn на macOS

{{< callout type="info" >}}
RuEn на macOS требует нескольких дополнительных шагов по сравнению с Windows и Linux. Следуйте инструкции ниже, если переключение языка работает нестабильно.
{{< /callout >}}

{{< details title="Первые шаги: включить режим Mac и выбрать правильную раскладку" closed="true" >}}

1. Нажмите **Toggle Ctrl/Gui** на клавиатуре — на экране должно появиться изображение яблока или надпись «Mac» (если включён режим экрана Modern или Minimalistic). Это активирует режим macOS, при котором RuEn Toggle отправляет **Ctrl+Space** вместо Win+Space.
2. В настройках macOS установите русскую раскладку **«Русская — PC»** (не «Русская»). RuEn ориентируется именно на эту раскладку.
3. Убедитесь, что состояние раскладки в клавиатуре совпадает с системой: включите режим экрана **Modern** или **Minimalistic** и нажмите **RuEn Sync**, если раскладки не совпадают.

{{< /details >}}

{{< details title="После бездействия клавиатуры первое переключение языка не срабатывает" closed="true" >}}

После того, как клавиатура простояла без использования несколько минут, macOS может проигнорировать первую команду переключения языка.

Обходной путь: нажмите несколько любых клавиш, а затем переключите язык. Для более стабильной работы увеличьте задержку в макросе переключения до **50 мс и выше**.

{{< /details >}}

{{< details title="При переключении языка вставляется лишний пробел" closed="true" >}}

Если комбинация переключения раскладки содержит Space (например, Opt+Space), при отправке через макрос M0/M30 символ пробела может попасть в текстовое поле.

Решение: увеличьте задержку между компонентами макроса (`Down → Delay → Up`). Рекомендуется начать с задержки **50 мс** и подобрать значение опытным путём.

{{< /details >}}

{{< details title="RuEn не переключает раскладку на macOS (системный хоткей нестандартный)" closed="true" >}}

Если в системе установлена нестандартная комбинация переключения, настройте макрос M0 на свою комбинацию, затем нажмите **RuEn M0**, чтобы клавиатура использовала этот макрос для переключения.

Инструкция: https://github.com/ergohaven/vial-qmk/pull/12

{{< /details >}}

## Особенности работы с двумя половинками

{{< details title="После обновления прошивки 3.4 одна из половинок перестала работать" closed="true" >}}

В прошивке 3.4 изменился протокол обмена между половинками. Половинки с разными версиями прошивки (например, 3.3 и 3.4) несовместимы друг с другом.

**Обязательно прошивайте обе половинки** при обновлении, желательно предварительно отключив их друг от друга.

{{< /details >}}

{{< details title="При подключении USB к другой половинке раскладка другая" closed="true" >}}

Каждая половинка имеет собственный контроллер с независимой памятью. Раскладка всегда берётся с той половинки, к которой подключён USB-кабель от компьютера (ведущей).

Если вы переподключились к другой половинке — откройте Vial и настройте раскладку заново, либо загрузите сохранённый `.vil`-файл.

{{< /details >}}

{{< details title="На ведомой половинке не переключается режим экрана" closed="true" >}}

Баг в старых прошивках. Обновите прошивку до актуальной версии.

{{< /details >}}

## Неполадки по моделям

### K:03

{{< details title="Vial выдаёт ошибку при первом запуске после обновления прошивки" closed="true" >}}

Попробуйте следующее:
1. Перезагрузите компьютер.
2. Переподключите клавиатуру в другой USB-порт.
3. Повторно обновите прошивку через bootloader.

{{< /details >}}

{{< details title="Функция RuEn работает только в английской раскладке" closed="true" >}}

Убедитесь, что состояние раскладки в клавиатуре совпадает с системой. Нажмите **RuEn Sync** один раз для синхронизации. Для проверки состояния включите режим экрана **Modern** или **Classic** — на нём отображается текущая раскладка.

{{< /details >}}

### Imperial44

{{< details title="Периодические зависания обеих половинок" closed="true" >}}

Зависания обычно связаны с нестабильной связью между половинками или проблемами с пайкой. Пошагово:

1. **Замените кабель** между половинками.
2. **Осмотрите плату** на наличие холодной пайки или остатков флюса. При обнаружении — пропаяйте и очистите.
3. **Снизьте скорость split-соединения**: в Vial откройте **QMK Settings** и уменьшите параметр скорости обмена. В прошивке можно задать `#define SELECT_SOFT_SERIAL_SPEED 5`.
4. **Откатите прошивку** до предыдущей стабильной версии.
5. Если ничего не помогло — обратитесь в поддержку для диагностики.

{{< /details >}}

{{< details title="Зависают клавиши двойного назначения (Space, Enter и другие)" closed="true" >}}

Проблема может быть вызвана некорректным значением **Tapping Term**. В Vial откройте **QMK Settings** и установите Tapping Term в диапазон 150–200 мс. Слишком малое значение (близкое к нулю) приводит к зависанию клавиш с двойной функцией.

{{< /details >}}

{{< details title="Как разобрать корпус Imperial44" closed="true" >}}

Плата сидит достаточно плотно из-за допусков при 3D-печати. Нажмите на плату через прорезь в корпусе каким-либо тупым предметом — хорошо подходит карандаш (резинкой вниз). Не используйте острые предметы: ими можно случайно замкнуть контакты.

{{< /details >}}

### HPD (High Plains Drifter)

{{< details title="Свитчи нажимаются туго, появился грубый тактильный бамп которого раньше не было" closed="true" >}}

Проблема характерна для изогнутых (curved) корпусов при использовании определённых свитчей. Плата слегка изогнута вместе с корпусом, из-за чего свитч зажимается в хотсвап-сокете. Попробуйте:
- Проверить каждый сокет отдельно: вставьте свитч и нажмите без кейкапа.
- При необходимости — обратитесь в поддержку для замены сокетов.

{{< /details >}}
